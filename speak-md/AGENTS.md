# speak-md — the pipe's rules

Dogfood TTS pipeline (markdown → flatten+respell → say/Moira). **Folded into
Blandings 2026-10-10** — abandoned before occupation, so a module of this silo,
not a silo of its own (`decisions/003-the-pipe-folds-in.md`). Environment
tooling, not okuda; speech is compositing — it belongs here.

1. **`just check` before every commit.** The golden test pins an empty
   lexicon, so learning never breaks it; the fixture must stay
   lexicon-independent (rule-covered constructs only).
2. **Lexicon entries are earned by ear.** A mangle heard, an entry added —
   never speculative, never bulk-imported. Commit as `lex: <word>`.
3. **espeak-ng never enters the data path.** Oracle only (`speak-md check`),
   out-of-band, both accents.
4. **Run artifacts stay in the silo's `tmp/` — never `/tmp`.** /tmp is
   governed by the OS (purged ~3 days, wiped on reboot), not by the
   silo: an artifact that can evaporate can't anchor the learning loop.
   `tmp/` is the scratch tier — exists, gitignored, regenerated by
   `just check` / `just demo`. Curated outputs graduate to git (golden,
   fixture). The boundary is the silo, not git.
5. **README is the registry.** If a directory accumulates documents, it
   gets an index in the same commit.
6. Flat is better than nested. Small is the design. Add directories only
   when they've earned their keep.
