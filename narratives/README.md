# narratives — the library

The speech library: texts read aloud, chosen for **prosody** — the comic periodic
sentence, the hard case — not for plot. The test is the Accelerator's note:
*agent telegraphese never exercises prosody; real prose does.*

## The two halves

Only texts that are **public domain worldwide** are committed here. Texts in
copyright anywhere the repository reaches are kept **local** and referenced by
title (`decisions/002-corpus-policy.md`).

| Text | Author | Year | Rights | Committed |
|---|---|---|---|---|
| `the-new-accelerator.md` | H. G. Wells | 1901 | public domain worldwide | yes |
| `company-for-gertrude.md` | P. G. Wodehouse | 1928 | US-PD 2024; **UK/EU copyright to 2045** | **no — local only** |

The Wodehouse is the impostor story — *Popjoy unmasked as Beefy Bingham* — and
Blandings' namesake. It is read from a **local file**, never committed: the
operator's jurisdiction is one where it is not yet free. If you are cloning this
repo, that text is not here by design, not by accident.

before occupation, and its library is this silo's
(`decisions/003-the-pipe-folds-in.md`).

timing rig.
